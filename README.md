# PDD Test

Жүргізуші куәлігінің теория емтиханына (ҚР ЖҚЕ) дайындалуға арналған жаттықтырғыш. Телефонға қосымша (PWA) ретінде орнатылады және интернетсіз жұмыс істейді.

**Ашу:** https://dani09934.github.io/pdd-test-kz/

## Мүмкіндіктер

| Бөлім | Не істейді |
|---|---|
| Басты бет | Прогресс, орташа балл, емтиханға дайындық, қателер саны |
| Тақырыптар | Тақырып бойынша жаттығу — жауаптан кейін бірден дұрысы көрсетіледі |
| Марафон | Барлық сұрақ кездейсоқ ретпен |
| Емтихан | 40 сұрақ / 40 минут, таймер, 32 дұрыс жауап — өтті (санын баптауда өзгертуге болады) |
| Қателер | Қате сұрақтар жиналады; қатарынан 2 рет дұрыс шешілсе, тізімнен шығады |
| Таңдаулылар | ☆ белгісімен қиын сұрақтарды сақтау |
| Сұрақтар қоры | Сұрақ пен жауап бойынша іздеу |
| Статистика | Тақырыптар бойынша прогресс, соңғы емтихандар графигі |
| Баптаулар | Діріл, жауаптарды араластыру, келесі сұраққа өту уақыты, емтихан ұзындығы, тақырып (жарық/қараңғы), прогресті файлға сақтау/жүктеу |

Сұрақ ішінде: свайп (солға/оңға) немесе ← → пернелері, 1–8 пернелерімен жауап беру, барлық сұраққа жауап берілгенде тест өзі аяқталады. GIF-ті қайта ойнату, 0.5× баяу көру және жүктеп алу.

## Құрылымы

```
index.html            — бет қаңқасы
css/style.css         — стильдер (қараңғы/жарық тақырып, мобильді нұсқа)
js/app.js             — логика: экрандар, тест қозғалтқышы, прогресс (localStorage)
js/pwa.js             — қосымша ретінде орнату, service worker тіркеу
sw.js                 — офлайн кэш
manifest.webmanifest  — қосымша атауы, иконкалар, жылдам сілтемелер
data/questions.js     — сұрақтар қоры
media/gif/*.mp4       — сұрақтардағы GIF-анимациялар
img/icon-*.png        — иконкалар
```

## Сұрақ қосу

`data/questions.js` ішіндегі `questions` тізіміне жаңа жазба қосыңыз:

```js
{"id": 2001, "topic": 0, "q": "Сұрақ мәтіні",
 "opts": [{"t": "Жауап 1", "ok": false}, {"t": "Жауап 2", "ok": true}],
 "img": "media/gif/new.mp4", "vid": 1}
```

Файлдарды өзгерткен соң `sw.js` ішіндегі `VERSION` мәнін көтеріңіз — телефондағы қосымша жаңарады.

## Жергілікті іске қосу

```
python3 -m http.server 8000
```
содан кейін http://localhost:8000 ашыңыз.
